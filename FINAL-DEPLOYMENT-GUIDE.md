## **🚀 Deploy to GitHub Pages:**

### **Step 1: Download Files**
Export/download all files from this workspace.

### **Step 2: Create GitHub Repo**
1. Go to https://github.com
2. Click **"+"** → **"New repository"**
3. Name: `1199-newsletter-jan-2026`
4. Make it **Public**
5. Don't add README
6. Click **"Create repository"**

### **Step 3: Upload Files**
1. Click **"uploading an existing file"**
2. Drag ALL 9 files + 2 folders (css, js)
3. Write commit message: "Initial newsletter upload"
4. Click **"Commit changes"**

### **Step 4: Enable GitHub Pages**
1. Go to **Settings** (gear icon)
2. Scroll to **"Pages"** in left sidebar
3. Under **"Source"**:
   - Branch: `main`
   - Folder: `/` (root)
4. Click **"Save"**
5. Wait 2-3 minutes

### **Step 5: Get Your URL**
Your site will be at:
```
https://[your-username].github.io/1199-newsletter-jan-2026
```
