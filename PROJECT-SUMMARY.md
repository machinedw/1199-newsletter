### Change App Name
Edit `manifest.json`:
```json

  "name": "Your Newsletter Name",
  "short_name": "Newsletter"
}
```

### Change Colors
Edit `css/style.css` line 15:
```css
:root {
    --bg-color: #FFFFFF;
    --text-color: #000000;
    --accent-color: #0066CC;
}
```

### Replace Icon
- Use https://favicon.io/favicon-generator/
- Generate 192×192 and 512×512 PNG icons

## 🐛 COMMON ISSUES & FIXES

### "404 Not Found" on GitHub Pages
- **Fix:** Make sure files are in repo root, not in a subfolder
- Wait full 3 minutes for deployment

### App won't install on Android
- **Fix:** Use Chrome browser (not Firefox)
- Ensure URL is https:// (secure connection)

### Images not loading
- **Fix:** Check internet connection on first load
- Try hard refresh: pull down to refresh on mobile

### Progress not saving
- **Fix:** Enable cookies/site data in browser settings
- Try different browser
